JPEG or PNG · A3 landscape · sorted by filename · up to 50 files (incl. intro & dividers)

How to use Upload your finished A3 pages above. Files sort by name — tip: number them, e.g. 01_business.jpg, 02_business.jpg. Drag thumbnails to reorder. Click a thumbnail to replace it. Click × to remove. Add your name and ID, then click Download PDF.
Typography check Use the same fonts on every page — one heading font and one body font. Body text 9–14pt. Avoid Chalkboard. Good choices: Andale Mono, Orator Std, Typewriter Condensed, or a clean sans-serif.
Harvard referencing reminder Every image you did not make must be credited on the page where it appears:
Artist, I. (Year) Title of work [medium]. Available at: URL (Accessed: DD Month YYYY).
Surname, I. (Year) Title of website page. Site name. Available at: URL (Accessed: DD Month YYYY).
Full guide: hsstokes.github.io/Harvard-Referencing-Guide

Builder not working? Use one of these instead

Same rules: A3 landscape · one page per slide/page · save as PDF.

PowerPoint

  1. Design → Slide Size → A3, Landscape
  2. Drag one page (JPEG) onto each slide
  3. File → Export / Save As → PDF

InDesign

  1. File → New → A3, Landscape, 20+ pages
  2. File → Place → one JPEG on each page
  3. File → Export → Adobe PDF (Print)
